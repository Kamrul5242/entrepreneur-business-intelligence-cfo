# Benchmarks and Reference Ranges

## How to use this file — read first

These are **orientation ranges, not standards.** A number outside a range is a
question to investigate, never a verdict on its own.

Rules when citing anything here:
1. Label it as a general range, never as "the industry standard."
2. Name the business model before comparing — a POD store and a SaaS company
   share no useful benchmark.
3. Ranges shift with geography, scale, channel mix, and year. Bangladesh
   e-commerce economics differ materially from US DTC.
4. If a decision hinges on a benchmark, tell the user to validate it against
   their own historical data or a current source rather than this file.
5. **Never state a benchmark with false precision.** "Roughly 20–40%" not "31%".

## Gross margin — typical ranges by model

| Model | Rough gross margin |
|---|---|
| SaaS / software | 70–85% |
| Digital products, courses | 80–95% |
| Services / agency | 40–60% |
| Print-on-demand | 20–40% |
| DTC e-commerce (own brand) | 40–65% |
| Apparel manufacturing / B2B sourcing | 15–35% |
| Retail / reselling | 20–40% |
| Marketplace / commission model | 60–90% on take rate |
| Grocery / FMCG distribution | 5–15% |
| Travel agency / OTA (on commission) | 5–15% of booking value |
| Restaurant | 55–70% food margin, thin net |

## Net margin — rough expectations

| Model | Net margin |
|---|---|
| Mature SaaS | 10–25% |
| Healthy DTC e-commerce | 5–15% |
| POD side business | 5–20% |
| Services / consulting | 10–25% |
| Retail | 2–6% |
| Distribution / wholesale | 1–5% |
| Restaurant | 3–9% |

A net margin under ~5% means almost no shock absorber. One bad month, one
supplier increase, or one ad-platform change removes the profit.

## Unit economics heuristics

| Metric | Common healthy zone | Read with |
|---|---|---|
| LTV : CAC | 3:1 often cited | Meaningless without payback period and margin |
| CAC payback | < 12 months (SaaS), < 3 months (e-com) | Cash position determines what's tolerable |
| Contribution margin after ads | > 20% | Below this, scaling is fragile |
| Break-even ROAS | `1 / CM ratio` | Compute it; never guess |
| Repeat purchase rate (e-com, 12 mo) | 20–40% | Category-dependent |
| Refund rate | < 5% | Apparel runs higher; sizing-driven |
| RTO rate (COD markets) | 10–30% | Major hidden cost in South Asia |

**On "3:1 LTV:CAC":** it is a slogan, not a law. A 3:1 with 18-month payback in
a cash-poor business is worse than 2:1 with 45-day payback. Always pair the
ratio with payback.

## SaaS reference points

| Metric | Rough healthy |
|---|---|
| Monthly logo churn (SMB) | 3–7% |
| Monthly logo churn (enterprise) | < 1% |
| Net revenue retention | > 100% is good, > 120% is strong |
| Gross revenue retention | > 85% |
| Rule of 40 | Growth % + Profit % ≥ 40 |
| SaaS quick ratio | > 4 signals efficient growth |

## Liquidity and leverage

| Metric | Common comfort zone |
|---|---|
| Current ratio | 1.5–3.0 |
| Quick ratio | > 1.0 |
| Debt-to-equity | < 2.0 for most SMEs |
| Interest coverage | > 3× |
| DSCR | > 1.25 (typical lender floor) |
| Runway (pre-profit) | > 12 months comfortable, < 6 urgent |

Very high current ratios can indicate idle cash or bloated inventory, not
strength. Read alongside inventory turnover.

## Cash cycle orientation

| Model | Typical CCC |
|---|---|
| SaaS / prepaid subscription | Negative (paid before delivery) |
| Restaurant / retail (cash sale) | Negative to slightly positive |
| DTC e-commerce (prepaid) | 20–60 days |
| Wholesale / B2B credit sales | 60–120 days |
| Manufacturing / apparel export | 90–180 days |
| Pre-order model | Negative by design — customer cash funds production |

## Concentration thresholds worth flagging

| Type | Flag above |
|---|---|
| Single customer share of revenue | 20% |
| Top-3 customer share | 50% |
| Single supplier share of spend | 50% |
| Single acquisition channel | 60% |
| Single platform (marketplace, ad account) | 50% of revenue |

---

## What this file cannot tell you

- Whether a specific price is right for a specific market
- Current ad platform CPM/CPC — these change monthly, look them up
- Current tax rates, VAT, duty, or compliance rules — jurisdiction-specific
- Current FX rates
- Valuation multiples for a live transaction

For any of these, use current sources or the user's own data. Do not substitute
this file for research.
