# NOTHING from this file - they are standard library only, by design.

# openpyxl is required only to build or verify the Excel workbook:
#   scripts/build_dashboard.py   writes assets/cfo-premium-dashboard.xlsx
#   scripts/verify_signature.py  reads its document properties
#
# The version is pinned because openpyxl changes archive layout between
# releases, which changes the workbook's SHA-256 and breaks the manifest match
# even when the content is identical.
#
# Hashes are pinned too, so a compromised or substituted artifact on the index
# cannot be installed silently. CI installs with --require-hashes, which makes
# pip refuse anything unpinned. Both distributions are listed for each package
# because pip verifies whichever one it selects.
#
# Both wheels are pure Python (py3-none-any), so this is platform-independent
# and does not affect Excel support on Windows.
#
#   python3 -m pip install --require-hashes -r requirements.txt
#
# To change a version, replace the hashes from the PyPI JSON API:
#   https://pypi.org/pypi/<package>/<version>/json
